# База данных «Салон сотовой связи»

Задача: спроектировать реляционную базу данных для салона сотовой связи (продажи, клиенты, товары, ремонты, платежи) и написать аналитические запросы.

Инструменты: MySQL, диаграмма в draw.io.

Что сделано:
- Спроектирована схема БД, приведена к 3НФ.
- Создано 13 таблиц (Клиенты, Сотрудники, Товары, Продажи, Позиции_Продажи, Устройства, Ремонты, Платежи, Категории, Тарифные_планы, Способы_оплаты, Должности, Остатки_товаров).
- Написаны 7 аналитических запросов:
  1. Список клиентов с их тарифами.
  2. Выручка по категориям товаров.
  3. Сотрудники с >1 продажи за месяц.
  4. Устройства клиента Кузнецова и статусы ремонта.
  5. Товары ниже порога пополнения.
  6. Клиенты с платежами, но без устройств.
  7. Средняя стоимость ремонта по техспециалистам.
