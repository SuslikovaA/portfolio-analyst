# Сегментация клиентов на основе потребительского поведения (Python)

Задача:
Построить модель классификации для сегментации клиентов по потребительскому поведению (целевая переменная `Segmentation` с классами A, B, C, D). Проект выполнен в рамках учебной курсовой работы.

Инструменты:
Python, pandas, sklearn (CategoricalNB, LabelEncoder, train_test_split, метрики), matplotlib, seaborn.

## Что сделано

### 1. Загрузка и первичный анализ данных
- Исходные данные загружены с помощью pandas.
- Выполнен анализ описательной статистики, выявлены распределения числовых признаков (Age, Work_Experience, Family_Size).

### 2. Визуализация данных
- Построены гистограммы и столбчатые диаграммы для понимания распределений.
- Диаграммы рассеяния (Age vs Spending_Score) с окраской по сегментам.
- Тепловая карта корреляции между признаками.
- Выявлено, что целевая переменная сбалансирована (классы A, B, C, D представлены равномерно).

### 3. Очистка и предобработка данных
- Пропуски: числовые (`Work_Experience`, `Family_Size`) заполнены медианой, категориальные (`Ever_Married`, `Graduated`, `Profession`) – модой.
- Выбросы: обработаны методом IQR (замена на границы).
- Дубликаты: удалены.
- Кодирование: 
  - Бинарные признаки (Gender, Ever_Married, Graduated) – LabelEncoder.  
  - Порядковый признак (Spending_Score) – OrdinalEncoder (Low < Average < High).  
  - Номинальный признак (Profession) – OneHotEncoder.
- Все признаки приведены к числовому формату.

### 4. Построение и обучение модели
- Выбран CategoricalNB (наивный байесовский классификатор для категориальных признаков).
- Данные разделены на обучающую (80%) и тестовую (20%) выборки с сохранением пропорций классов (stratify).
- Создан конвейер (Pipeline) для обеспечения воспроизводимости.

### 5. Оценка качества модели
- Accuracy: 51.7% 
- Precision / Recall / F1-score: ~0.50–0.52 – умеренная способность к обобщению.
- **Матрица ошибок:**  
  - Сегменты C и D распознаются лучше (>60% точности).  
  - Сегменты A и B – хуже (<50%), особенно B – самый сложный для модели.
- ROC-AUC для класса D: 0.881
- 
### 6. Интерпретация результатов
Составлены профили каждого сегмента (возраст, пол, семейное положение, профессия, потребительская активность). Например:
- Сегмент D: молодые (≈27 лет), без высшего образования, очень низкая потребительская активность.  
- Сегмент B: старший возраст (≈54 года), высокая потребительская активность, часто руководители.

Эти профили позволяют предлагать целевые маркетинговые стратегии.

## Вывод
Модель демонстрирует базовый, но рабочий уровень для задачи сегментации. Лучше всего выделяется сегмент D (AUC 0.88). Проект показывает владение полным циклом анализа данных: от очистки до интерпретации.
